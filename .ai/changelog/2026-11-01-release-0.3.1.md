## Summary

Patch release for a data-loss bug in 0.3.0: a partial update of a project or initiative (for
example a rename) reset its other fields — description, status, lead, dates and members. Also
ships saved and shared views and the timeline layout for issues and projects.

## Notes

Migration 0025 (`saved_views`) is additive. Values already lost on 0.3.0 cannot be recovered
from Ordler, because the audit log stores only new values; restore them by hand or from a
database snapshot.
