# Release 0.3.0

- Date: 2026-10-29
- Area: infra, docs
- Spec: §16.5

## Summary

Ships everything since 0.2.2: cycles, projects and initiatives; import from Linear and Jira;
webhooks; the public REST API v1; SLA with business hours; approval timeouts, escalation and
out-of-office delegation; conditional form fields, conditional approval steps and routing
rules; link previews for messengers; copy ID and link on issues. New installs keep their
tables in the `public` schema. The README now carries a full deployment guide and a DevOps
ticket template.

## Changes

- `deploy/helm/ordler/Chart.yaml` — chart and app version 0.3.0.
- `README.md` — feature overview, "Deploy in your company" (network, Helm values, Compose,
  backups, upgrades, monitoring, configuration) and a ticket template for DevOps.
- `docs/SPEC.md` — table formatting fixed for the format check.

## Tests

- Full suite, type-check, lint and format pass locally; CI green before tagging.

automatically.
