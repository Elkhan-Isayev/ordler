# @mentions in issues and comments

- Date: 2026-10-22
- Area: api, web, shared
- Spec: §5.1 Watchers, §7

## Summary

Typing "@" in an issue description, a comment or the new-issue dialog lists the team's
members; picking one inserts a mention. Newly mentioned people get an Inbox notification and
an email, but only if they can read the team, so a mention never reveals a private issue.

## Changes

- `packages/shared/src/issues.ts` — mentions stored as Markdown links
  `[@Name](/people/<member id>)`; `extractMentions`; notification kind `issue_mentioned`.
- `apps/api/src/issues/issue.service.ts` — notify on create, description edits, new and edited
  comments (only newly added mentions); mentioned people are not also sent the generic
  comment notification. Email subjects in en/ru/de/az.
- `apps/web/src/editor/RichEditor.tsx` — "@" suggestions with mouse and keyboard
  (arrows, Enter/Tab, Escape); mentions render as name chips.
- Issue page, comments and the new-issue dialog offer the team's members; i18n en/ru/de/az.
