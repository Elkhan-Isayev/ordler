# Linear-style search by number or title

- Date: 2026-11-12
- Area: web, api, shared
- Spec: §5.4

## Summary

Search is easier to find and use: a search field in the sidebar, `Cmd/Ctrl+K`, `Cmd/Ctrl+F`
and `/` open it; a bare number finds issues and requests in every readable team, number
matches rank first, and wiki pages appear in the results.

## Changes

- apps/api — issue and request search accept a bare number and rank identifier matches first;
  `GET /api/search` also returns `wikiPages` (readable spaces only).
- packages/shared — `SearchResults` response type.
- apps/web/src/components/CommandPalette.tsx — `Cmd/Ctrl+F` and `/` shortcuts, results grouped
  into Issues / Requests / Wiki, a hint before typing, wiki pages open from the palette.
- apps/web/src/components/Sidebar.tsx — search field with the platform's shortcut hint.
- Locales en/ru/de/az — `search.hint`, `search.groups.*`, new placeholder.
