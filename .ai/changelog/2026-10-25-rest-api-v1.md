# Public REST API v1

- Date: 2026-10-25
- Area: api, web, docs
- Spec: §10, §10.1

## Summary

`/api/v1` exposes teams, issues, comments, requests and search to scripts and integrations.
It authenticates only with personal access tokens, honours their scopes, runs through the same
services and RBAC as the UI, pages with stable cursors, replays POSTs that repeat an
`Idempotency-Key`, and is described by a generated OpenAPI 3.1 document.

## Changes

- `apps/api/src/api-v1/public-api.ts` — route table, token auth, scopes, per-token rate limit (600/min), cursor pagination, idempotency, OpenAPI from shared Zod schemas.
- `apps/api/drizzle/0021_api_idempotency.sql` — `api_idempotency_keys` (additive).
- `apps/api/src/app.module.ts`, `apps/api/src/app-context.ts` — routes and limiter.
- `apps/web/src/settings/TokensPage.tsx` — REST API address and OpenAPI link; locales `en`, `ru`, `de`, `az`.

## Tests

- `apps/api/src/api-v1/public-api.http.test.ts` — token-only auth, scopes, private team invisibility, issue create/update/comment via token, cursor pages and `updated_since`, idempotent replay and key reuse, requests, no approval route, rate limit, OpenAPI document, cursor stability.
- `apps/web/src/settings/TokensPage.test.tsx` — REST API hint.

## Notes

Approvals cannot be decided through the API. Admin operations are not part of v1.
