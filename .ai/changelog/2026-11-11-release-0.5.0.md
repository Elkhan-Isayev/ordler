# Release 0.5.0

- Date: 2026-11-11
- Area: infra, docs
- Spec: §5.5, §16.5

## Summary

Adds whiteboards: Miro-style canvases edited live by several people, attachable to issues
and shown inside them, and drawable by AI agents through MCP (ADR 0015).

## Changes

- `deploy/helm/ordler/Chart.yaml` — chart and app version 0.5.0.
- `README.md` — pinned examples and the DevOps checklist point to 0.5.0.

## Tests

- Full suite, type-check, lint and format pass locally; CI green on `main` before tagging.
- Checked live: an agent's diagram over MCP, two tabs drawing on one board, an image placed on
  a board and shown in the issue's embedded board.

## Notes

Migration 0030 is additive. New runtime dependencies: `@excalidraw/excalidraw` (web),
`fractional-indexing` (API). The image grows by about 13 MB of editor fonts.
