# Department wikis

- Date: 2026-11-12
- Area: api | web | shared | docs
- Spec: §5.6, §4.3, §10.1, §12.1

## Summary

Every department gets a Wiki.js-like knowledge base: nested folders, Markdown pages with
version history and conflict protection, diagrams as embedded live whiteboards, import from
Wiki.js by API key, and MCP tools so agents can read and write pages.

## Changes

- `packages/shared/src/wiki.ts` — schemas, views, embed helpers; permissions `wiki.read`,
  `wiki.edit`; token scope `wiki:write`.
- `apps/api/drizzle/0031_wiki.sql` — wiki tables, `departments.wiki_visibility`,
  department-owned attachments (additive).
- `apps/api/src/wiki/` — access rules, service, controller, Wiki.js client, HTML → Markdown
  converter, background import.
- `apps/api/src/mcp/` — wiki tools, `ordler://wiki/{id}`, `create_whiteboard` → `wikiPage`.
- `apps/api/src/rbac/db-access-context.ts` — team grants load the team → department directory.
- `apps/web/src/wiki/` — wiki home, space, page (edit, history, restore), embeds, Wiki.js import.
- `apps/web/src/editor/RichEditor.tsx` — tables and checklists.
- Locales en/ru/de/az; docs: ADR 0017, SPEC, README, CLAUDE.md.
