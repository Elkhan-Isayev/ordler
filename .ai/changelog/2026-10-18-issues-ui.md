# Issues UI: board, list, issue page and live updates

- Date: 2026-10-18
- Area: web
- Spec: §5.1, §5.3, §5.4; ADR 0007

## Summary

Teams now have a list and a drag-and-drop board, an issue page with editable fields,
properties and history, and My issues. Every open tab stays in sync over the realtime
channel; edits apply instantly and roll back if the server refuses them.

## Changes

- `apps/web/src/realtime/client.ts` — one WebSocket per tab, reference-counted topics,
  reconnect with backoff and jitter, refetch after reconnect, `useRealtime` hook.
- `apps/web/src/issues/` — `useTeamIssues` (load, live merge, optimistic update with
  rollback), `IssueBoard` (HTML5 drag and drop, positions between neighbours), `IssueList`
  (by status or by category), `NewIssueDialog`, `TeamIssuesPage` (`/teams/KEY/issues`,
  `/teams/KEY/board`), `IssuePage` (`/issue/KEY-N`), `MyIssuesPage` (`/my-issues`).
- `apps/web/src/components/Sidebar.tsx` — Board link, current page highlighted, the open
  team expanded.
- `apps/web/vite.config.ts` — the dev proxy forwards WebSocket upgrades.
- `packages/shared/src/issues.ts`, `apps/api/src/issues/issue.service.ts` — summaries carry
  the status (name, key, category) for cross-team lists.
- i18n for en, ru, de, az; history lines use neutral wording, so no grammatical gender is
  guessed.

## Tests
