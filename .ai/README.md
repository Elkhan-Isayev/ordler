# .ai

Working notes maintained by AI agents (and humans) for this repository. Written in English.

## changelog/

One file per change set — never a single growing file.

- File name: `YYYY-MM-DD-<short-kebab-slug>.md` (e.g. `2026-10-14-approval-step-timeouts.md`).
  If two entries share a date and slug, append `-2`.
- Content: copy [`changelog/_TEMPLATE.md`](changelog/_TEMPLATE.md) and fill every section.
- Past entries are history: correct typos only; describe later changes in a new entry that
  links back to the earlier one.
